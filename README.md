一、PHP2Shell：网页万能钥匙被复制
1. PHP是一种网站后台的“发动机”语言。大量网站（尤其内容管理系统、电商、论坛）都用它来生成动态页面、连接数据库。
2. 这次曝出两个不用账号密码就能远程控制服务器的漏洞，影响PHP 5.4到8.5.11的几乎所有版本。10月21日官方发布了补丁，但8.1及更早的版本官方不再提供修复。
二、GitLab：评分满分10分的“无门禁入侵”
1. GitLab是一个软件研发的“一站式工作台”。开发团队用它存放代码、审查修改、自动测试和部署上线。很多公司把它装在自己的服务器上（自建GitLab）。
2. 自建GitLab从7.0版本起全部受影响。攻击者不需要登录，只需提交一个精心构造的正则表达式，就能在服务器上执行任意代码。官方已于10月21日发布修复版本。
三、LiteLLM1.107.0：恶意版本导致密钥全丢
1. LiteLLM是AI应用常用的工具包，许多AI产品和智能体背后都用它来管理密钥、分配请求和控制成本。
2. 10月21日，其发布流程被攻破，恶意版本1.107.0在PyPI和Docker上挂了约1小时44分钟。一旦安装并启动，它会偷走SSH密钥、云服务凭据和AI工具密钥，并留下后门。
四、Node.js：三条版本线出问题，最严重的可远程执行代码
1. Node.js是一个让JavaScript跑在服务器上的运行环境。很多网站后端、实时应用（聊天、协作工具）、API服务都靠它运行。
2. Node.js22、24、26三条版本线一共修了10个漏洞。最严重的是Brotli解码器越界写入(CVE-2026-111497)，可能导致远程执行代码，评级“高危”。
五、eMudhra：证书机构的“锁”被秒开，HTTPS信任根基被动摇
1. eMudhra是一家印度的“数字身份证/证书颁发机构”。
2. 这家机构的八张中间证书相关私钥存在严重安全问题，密钥强度异常薄弱，可能被用于伪造受信任的网站证书。Chrome、Firefox和Apple已经封禁了这些证书。
六、Railway：托管平台“保险箱”被撬，部分密码已泄漏
1. Railway是一个面向开发者的云部署平台。
2. 托管平台Railway被人访问了加密的环境变量，其中一部分已经被解密。部署已暂停，官方要求所有用户轮换密钥。
七、Agent2Shell：AI编程助手“先执行，后询问”
1. Agent2Shell是一类针对AI编程助手的攻击方式。涉及的AI编程工具（如Claude Code、Cursor、Codex、Gemini CLI）是帮开发者自动写代码、改代码、执行终端命令的智能助手。
2. 攻击者在仓库里放一个恶意配置，Claude Code、Cursor、Codex和Gemini就会在调用模型、弹出信任确认之前执行攻击者的代码。
八、Cisco Expressway：不用登录就能以root身份控制设备
1. Cisco Expressway是思科的企业视频会议/统一通信网关。
2. 10月21日，Cisco披露Expressway系列存在一个满分边缘级漏洞。攻击者无需认证，只要能访问设备，就能以root权限执行任意操作系统命令，且没有临时缓解措施，只能打补丁。
九、CISA新增六项遭利用漏洞
1. 美国网络安全和基础设施安全局（CISA）10月20日将6项漏洞加入已知遭利用漏洞目录，涉及Plex Media Server、EG Secure Solutions SiteGuard Server Edition、西门子Software Center等产品。其中西门子Software Center的DLL侧加载漏洞（CVE-2026-110936）已被确认存在活跃利用。
