2026.10.14【收评：你恐惧还是麻木？】
        今天的市场，最值得关注的不是某个板块突然拉升，也不是沪指能否勉强维持强势，而是创业板已经跌破450天线。走到这一步，说明市场调整的压力依然很大，前面期待的支撑并没有如期稳住。但我认为，现在还没有必要因为跌破450天线，就急着认定市场接下来必然加速下跌。创业板距离610天线仍有200多点的空间，这中间依然存在腾挪的余地。
        今天有一点尤其重要：跌势太快，不应该急着动作。当市场连续下跌、情绪明显转弱时，很多人容易陷入两种极端：一种是恐慌割肉，另一种是认为跌得多了就一定会反弹，急着抄底。我的态度是，这两种做法都容易被情绪牵着走。既然创业板已经跌破450天线，就更应该让市场先走出自己的节奏。接下来究竟是继续下探，还是出现技术性修复，需要观察后续走势再作判断。今天不急着做决定，等明天再说。
          这轮调整，也再次提醒我们一个老问题：一切都是因果。前期有些股票并没有足够扎实的业绩支撑，却靠着概念、故事和资金追捧不断被爆炒。股价上涨时，很多人觉得自己抓住了风口，甚至把短期炒作当成了长期价值。只要股价继续涨，风险就好像不存在；一旦市场情绪逆转，资金开始撤退，真正的问题才会暴露出来。估值过高、业绩不足、缺乏安全边际，这些风险不会因为股价上涨就自动消失。
         爆炒垃圾股，总要付出代价。我说这句话，不是为了嘲笑被套的人，而是希望大家真正记住这次教训。股票下跌，亏损固然难受，但比亏损更可怕的，是同样的错误反复发生。今天被套了，明天行情一有好转，又忘记了这次为什么被套；下一轮热点出现，又忍不住追进去。如此循环，市场每一次调整都可能成为重复交学费的过程。
         如图，今天板块涨幅榜跌多涨少，我看好的板块接近半数，它们有一个共同特点：“低估值”，这三个字非常重要，如果理解这三个字，你一生的投资之路会少损失很多钱，在任何投资之前远离所有主流媒体，因为它们总是散布不实消息，要从股市实际估值考虑风险，在足够的反思风险后，再交易一定不会有恐惧感！
