2026.9.21【午评：吃相太难看】
       今天A股继续反弹，创业板早盘一度明显走强，半导体、MLCC、CRO、通信设备等科技方向重新活跃。表面上看，市场情绪不错，但我反而更加警惕，因为我们前面反复说过的问题并没有解决。最值得注意的，还是“遍地开花”又出现了。半导体、医疗、通信、传媒等多个方向同时活跃，资金看起来很热闹，实际上却很难形成真正能够持续推动指数的核心主线。
        9月18日市场已经出现过一次大面积上涨，今天如果继续复制这种模式，我认为反弹的持续性反而值得怀疑。尤其是科技股。半导体今天继续走强，但问题依然存在：真正低估值、业绩确定性又足够强的科技股并不好找。市场如果再次依靠高估值概念股推动行情，最后还是会回到估值和资金承接的问题上。反复炒概念、炒题材，并不能真正解决市场的压力。
        与此同时，前期表现较好的贵金属、油气等方向今天出现调整。这个现象反而说明资金正在快速切换。资金没有消失，但热点不断迁移，恰恰容易形成我们最担心的“遍地开花”。这种行情看起来很强，实际上最容易冲高之后重新分化。
         创业板才是我目前最关心的地方。上周五创业板收于3372.68点，今天早盘继续向上反弹，但上方压力依然很大。我的观点没有改变：创业板377天线不到，调整就不能轻易宣布结束。现在这种边跌边涨、反复拉高指数的方式，我认为还是之前走过的老路。真正痛快的调整反而能够释放压力，如果一直靠反弹拖延，后面的压力只会越来越大。
