           今天最值得关注的，不是指数跌了多少，而是沪指触及610天线后出现回升。610天线是我长期观察市场的重要技术位置，也是判断市场中长期趋势的关键参考。但我不认为触及610天线后回升，就意味着市场已经见底。下降趋势在最后见底之前，任何下影线都看跌，而上涨趋势在最终见顶前，任何上影线都看涨，我对K线的认识就是这样，所以很显然沪指的下影线只是下跌方向指引，并非见底的迹象！
        我的判断很明确：这更像是下跌过程中的技术性抵抗，属于下跌中继，而不是新一轮上涨的起点。指数跌到重要均线附近，出现资金承接并不奇怪，但真正的底部必须经得起后续市场的检验。如果反弹缺乏持续性，个股仍然大面积下跌，那么沪指即使暂时守住610天线，也不能证明调整已经结束。
         创业板和科创50的表现尤其值得警惕。创业板指下跌2.14%，科创50下跌3.07%，说明高估值、高预期的成长板块仍然承受着沉重压力。此前被反复炒作的科技概念，不能因为偶尔反弹就重新获得安全边际。估值过高、业绩支撑不足的问题没有解决，调整就可能继续。对于这些板块，我依然不赞成盲目抄底。科创板是最应该击破610的高估板块，你们看还差多远？
          我的操作观点不变：目前仍应保持谨慎，把这次回升先视为下跌中继，而不是急着宣布市场见底。没有把握的行情就继续等待，现金也是一种选择。真正值得参与的机会，不是看到指数跌多了就冲进去，而是等市场用实际走势证明风险已经明显释放。
