【日媒曝日本政府考虑增税筹措防卫费】金十数据10月17日讯，据日本共同社17日报道，日本政府正考虑通过进一步提高企业的法人税，为预计将持续膨胀的防卫费筹措资金。媒体称有关计划可能引发经济界反对。报道说，日本政府正在推进“安保三文件”修订，其中，新一轮覆盖2027至2031财年的《防卫力整备计划》提出大量采购无人机、增加弹药和导弹储备，为长期作战做准备。报道援引日本政府高层人士的话称，如果按照防卫省所需进行估算，未来5年日本防卫费总额“可能膨胀至70万亿至80万亿日元（1美元约合158日元）”。（新华社）

【泽连斯基称“星链”限速仅针对乌克兰 已掌握证据】金十数据10月17日讯，当地时间17日，乌克兰总统泽连斯基表示，乌方通过在欧盟国家开展对比测试获得证据，显示“星链”卫星通信终端的速度限制仅在乌克兰境内生效。泽连斯基指出，目前乌境内“星链”终端时速限制为161公里，一旦超速便完全失去连接，导致依赖该系统的无人机失控。为查明这究竟是技术故障还是有意限制，乌方派出多辆配备终端的车辆赴欧盟国家测试——在允许高速行驶的道路上，车辆以超过180公里时速行驶时，终端仍保持正常运行。泽连斯基称，乌方已保存测试记录并掌握相应证据。他据此认为，相关限制并非普遍技术问题，而是一项有计划实施的行动。他同时质疑，此举是否意在削弱乌克兰防御能力，使其难以有效保护前线军人和平民。
