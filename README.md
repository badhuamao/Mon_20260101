       今天的市场，调整压力进一步释放。创业板在跌破450天线之后，继续承受较大的抛压，沪指也一度失守3700点。面对这样的走势，我认为没有必要再回避现实：当前市场确实偏弱，短期风险仍然存在。但越是在这种时候，越不能只盯着眼前的跌幅，更不能因为指数连续下跌，就急着判断下一步必然会怎样。
        今天最值得关注的，是市场下跌的广度和速度。当大量个股同步走弱，说明压力已经不只是集中在某几个板块，而是市场整体风险偏好正在下降。尤其是前期涨幅较大、估值较高的科技成长方向，一旦资金开始撤退，股价调整往往会比指数更加剧烈。这个时候，不能因为某些股票跌得多，就简单地认为它们已经便宜。价格下来了，不等于价值就出现了。
          至于610天线，我仍然把它视为后续重要的技术观察位置，但不是一个必然到达的终点，更不是到了那里就一定见底。市场有自己的运行节奏，途中可能出现反弹，也可能反复考验支撑。真正值得关注的是，当指数继续下探时，是否开始出现有力度的承接；当反弹出现时，能否持续，能否带动更多个股回升。只有这些信号逐渐改善，才有理由讨论调整是否接近尾声。
         今天我在直播中和学生说中国股市最大的风险不在于做空，而是严重缺乏做空工具，文盲炒股、外行管理之下，股市的做空工具形同虚设，而国外股市的经验证明，足够的做空工具才是股市长期稳定的基石，只能做多的情况下当产生系统性风险多杀多，所有人只会卖出，而有做空工具做空，获利后就会考虑回补仓位，出现空翻多！
