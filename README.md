【欧洲央行行长拉加德：欧洲整体通胀升温 但基本面指标保持稳定】金十数据11月7日讯，欧洲央行公布了欧洲央行行长拉加德接受日本读卖新闻采访的内容。在被问及如何看待目前的通胀前景时，欧洲央行行长拉加德表示，10月份总体通胀率为4%，高于几个月前的预期，但与市场预期相符。这个数字看起来很高，但深入分析其背后的原因至关重要。高企的读数主要归因于能源价格的上涨，因为受中东冲突和全球炼油产能下降的影响，能源通胀率从9月份的18.9%上升至20.8%。因此，能源价格对我们的通胀数据产生了重大影响。食品通胀率也有所上升。但基本面指标保持稳定。剔除能源、食品、酒精和烟草价格后的核心通胀率为2.5%，与9月份持平。服务业通胀率小幅上升至3.3%，但仍处于过去四个月的区间内。我们目前仍未获得通胀的详细构成数据，这些数据将有助于进一步阐明推动服务业通胀的因素——即通胀主要源于交通等能源密集型行业，还是我们已开始看到更广泛的间接影响。我们将对此进行密切关注。无论如何，我们知道未来几个季度通胀数据仍将居高不下。通胀率越高，持续时间越长，对我们中期目标的风险就越大。
