这种连续调整之后的情绪崩溃，通常会对应几类K线表现，比如放量杀跌的大阴线、低位十字星，或者缩量的光脚小阴线。本质上都是市场在连续下跌之后，恐慌情绪集中释放的表现。
今天下午一路下行，尾盘又出现加速回落，结合前面连续阴线来看，已经带有比较明显的“恐慌盘”特征。
从经验上讲，恐慌盘往往容易出现在一个阶段性调整的后半段，甚至接近尾端。
再看技术位置，目前指数只是重新回到了收敛三角形内部，距离下沿支撑并没有太大空间。小周期上，15分钟和30分钟已经进入超卖区域，60分钟向下空间也在收窄。
所以只要后面没有真正跌破收敛结构，今天这种情绪集中释放，反而有可能成为阶段性拐点逐步形成的前兆。
但大家要注意：
拐点临近，不等于马上反弹。
交易上还是那句话，个股破位就要重视风控。
如果手中个股已经破位，但仓位本身很小，可以再观察一下后续修复情况。
但如果仓位比较重，还是建议按照纪律处理。即便舍不得直接止损，也至少先把仓位降下来，把风险和情绪压力先控制住。
因为恐慌盘出现，只能说明调整可能逐步进入后半段，并不能保 证明天立刻上涨。仓位太重，在接下来的震荡里，心理上反而更容易被反复折磨。
现阶段最重要的，不是猜明天是不是最低点，而是先把仓位调整到自己能够承受的位置，再等市场真正给出止跌信号。
