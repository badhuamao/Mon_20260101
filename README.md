         我一直反对脱离业绩、单纯依靠故事推动股价的炒作。过去一段时间，科技概念受到资金追捧，部分股票的估值被推到了很高的位置。股价涨得越高，市场对未来增长的预期就越苛刻，一旦业绩无法兑现，估值回归就可能带来沉重压力。科创板并不是因为名字带有“科技”二字，就可以获得无限高的估值。科技产业有前景，不等于相关股票永远值得高价买入；把产业前景直接等同于股票投资价值，是很多投资者容易犯的错误。
         今天科创50逆势上涨，更不能说明风险已经解除。我的判断很明确：科创板估值处于高位，未来存在较大的补跌风险。前期科技概念被反复炒作，正是市场积累风险的重要来源之一。如果资金开始重新审视估值和业绩，那么今天的强势并不意味着明天还能继续强势。高估值板块一旦失去资金接力，调整往往不会因为过去涨得好就手下留情。对于仍然靠概念和预期支撑高价的股票，我不会因为它们今天上涨，就改变自己的看法。
         技术面上，创业板跌幅明显大于沪指，说明成长方向的压力仍然突出。450天线失守之后，我继续把610天线作为重要的长期观察位置。接下来，如果创业板持续弱于沪指，而高估值科技股又出现集中调整，那么市场就需要面对更大的下行压力。不要因为科创50一天上涨，就忽视整个成长板块所面临的估值问题。指数的短期强弱可以变化，但高估值最终需要业绩来支撑，这是绕不过去的现实。
