【我国牵头的虚拟电厂一次调频国际标准正式立项】金十数据11月13日讯，我国牵头提出的虚拟电厂国际标准提案，近日在国际电工委员会（IEC）成功立项。这项名为《虚拟电厂第4部分：一次调频功能要求与规范》的国际标准，聚焦虚拟电厂快速稳定电网的核心能力，联合多国专家制定全球统一技术准则，标志着我国在虚拟电厂国际标准化领域迈出关键一步。虚拟电厂并非实体电厂，而是依托数字技术将屋顶光伏、储能电池、充电桩、可调空调等分散设备聚合，统一调度、协同运行。虚拟电厂虽无厂房和机组，却能形成可观的调节能力，为电网提供调峰、调频等辅助服务。
