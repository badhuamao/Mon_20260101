2026.9.15【收评：要理解市场的语言】
        指数没有出现特别剧烈的波动，但个股明显偏弱，创业板午后继续承压。与此同时，风电、PCB、小金属等局部板块又有表现。看起来热闹，实际上资金还是在不断换地方。这恰恰验证了我最近一直强调的一点：市场现在最需要的是调整，而不是急着重新制造一轮普涨。
         前几天跌得快，我反而认为是好事情。上涨过程中积累的获利盘、套牢盘和情绪压力，如果能够通过一轮快速调整释放出来，后面反而更容易重新建立市场信心。最怕的不是跌，而是每天磨一点、反弹一点，压力始终悬在那里。
         创业板的问题依然没有解决。我的观点没有改变，377天线该碰还是要碰。 这不是说创业板碰到377天线就一定马上上涨，而是从我自己的技术判断来看，没有完成这个过程，就不能轻易把目前的调整定义为结束。
         所以现在看到创业板反弹，我不会兴奋；看到它继续下跌，我也不会恐慌。该跌的时候让它跌，该调整的时候就把调整做充分。
         再说板块。今天风电、小金属、PCB等方向活跃，但我并不认为这意味着新的“遍地开花”行情又来了。真正值得关注的，是这些板块能不能形成持续性，以及资金能不能从高位题材逐渐流向低位、有业绩或者有实际产业逻辑的方向。
         我依然比较关注证券、电力、燃气、油气、有色、贵金属以及部分低位周期股。市场经过这轮洗牌之后，真正的机会不会平均分配给所有股票，而是会重新集中到少数方向。现在最重要的不是猜哪一天见底，而是让市场自己把底部走出来。
          今天收盘之后，我还是那句话：别怕快跌，怕的是调整不彻底；别怕市场分化，怕的是重新遍地开花。真正值得期待的行情，从来不是所有股票一起涨，而是资金经过筛选之后，找到真正值得持续攻击的方向。
