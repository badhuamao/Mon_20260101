机构：显示行业告别规模扩张 超大尺寸与OLED成竞争主线
9月16日至17日，2026Omdia中国显示产业研讨会在上海举办。大会围绕大尺寸显示市场发展进行分析，认为行业总量增长有限，但产品结构向大尺寸快速迁移。同时，国内面板企业主导地位进一步巩固，高世代OLED产能建设正开启新竞争周期。Omdia资深首席分析师吴荣兵表示，在OLED赛道，过去韩国厂商占据高世代OLED接近98%市场份额，随着京东方B16、华星T8、维信诺V5产线逐步爬坡释放产能，预计2030年至2031年，国内高世代OLED产能面积占比有望达到30%，多技术路线并行，本土供应链迎来发展机遇。从需求端看，Omdia数据显示，2026年全球电视面板全年出货预计约2.4亿片，总量小幅回落，但内部尺寸结构发生显著变化。受存储、芯片等元器件成本上涨影响，需求向55英寸及以上产品转移。未来两到三年，大尺寸面板或将出现旺季抢货现象。（上证报）
