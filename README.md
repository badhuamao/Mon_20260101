中信证券提出四种配置思维来应对当下的市场。一是稳健回报策略，核心是围绕高股息或具备供给出清潜力的行业，在需求线索混沌的阶段聚焦供给的变化。二是预期演绎策略，类似于“2022年的航空和酒店”，找到市场对基本面一致看空，持仓比例极低的板块，拿到最终政策变化的时点再兑现，只做估值修复博弈。三是海外利率回落策略，把北美AI投融资预期修正、海外长端利率相应回落作为宏观前提，待市场修正EPS预期后，看非AI领域的制造业出海和资源股能否走出短期需求抑制。四是赛道热度+筹码出清策略，类似于找寻“2022年的户储和逆变器”，以新领域需求的超预期爆发作为抄底科技的时机，寻找机构和活跃资金能够共振的领域，而非简单博弈“无机”。中信证券认为四种策略都有获取相对收益的潜力，适合不同收益-风险偏好的资金，市场的资金面压力决定了哪类策略阶段性占优。
