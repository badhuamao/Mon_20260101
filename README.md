中金 ：邮储银行首三季业绩符合预期，H股目标价升至7.12港元
中金发表研报指，邮储银行首三季业绩符合该行预期。净利息收入同比增长4.6%，主要受成本较低的自营存款快速增长及存款利率下调推动，负债成本持续改善；惟受资产端收益率下行压力影响，净息差环比下降3个基点至1.6%。公司大力发展第二增长曲线，非息收入同比增长12.63%，其中净手续费增长8.7%，其他非息收入增长15.5%，非息收入占比21.83%，同比上升1.24个百分点，收入结构优化。对公贷款成为信贷扩张主要驱动力，资产质量整体保持稳定，不良贷款率0.99%，拨备覆盖率204.74%。考虑到净利息收入增速有所放缓，该行维持2026年营收预测基本不变，下调2027年营收预测2.3%至3974亿元；维持2026及2027年归母净利润预测不变。该行上调A股目标价11.3%至7.28元，上调H股目标价14.1%至7.12港元，较当时股价分别有约27.1%及26.7%上行空间，维持“跑赢行业”评级。

摩根大通 副董事长：AI板块估值仍高 预计将出现回调
摩根大通副董事长Daniel Pinto认为，AI领域的估值仍然过高，并预计该行业将会出现回调。Pinto在香港金管局举办的国际金融领袖投资峰会一场小组讨论中表示，确实相信生产力将迎来一波大幅提升，也相信AI会带来重大影响。但他提醒大家，要审慎看待增长的速度，因为目前正在开发的所有这些东西，终究得有人买单。AI以外的产业以及其他所有人，必须向这些公司支付数以万亿计美元，才能证明这些投资是合理的。他表示，AI公司需要证明如此庞大的投资规模以及目前的估值是合理的，现在的步伐可能有点太快了。Pinto表示，AI产业可能会出现“回调”。他表示，相较于这些公司目前的市场价格，市场对其营收和获利增长的预期可能有些过于陡峭，这可能导致整个产业重新定价。

中信建投 正申报SFISF操作 称三大因素有望推动A股见底回升
11月3日，记者获悉，中信建投证券正积极申报第三批“证券、基金、保险公司互换便利（SFISF）”操作。中信建投表示，坚定看好我国资本市场长期发展，切实发挥作为资本市场“排头兵”和机构投资者“压舱石”的作用，助力资本市场健康稳定发展。11月3日，中信建投首席经济学家黄文涛还发布市场评论称，近期A股市场持续震荡调整，目前已经进入底部区域，三大因素有望推动A股见底回升，包括监管部门协同发力稳定市场信心、三季报业绩亮点逐步显现、部分行业估值吸引力明显提升。据黄文涛介绍，经过近期回调，前期科技成长板块估值偏高、交易拥挤等压力有所释放，部分优质资产的估值性价比正在改善。截至11月3日午盘，创业板指市盈率已从前期53.5倍的高位回落至27.7倍，为近十年6.45%分位水平；科创50市盈率也从前期250倍高点大幅回落至当前89倍。估值调整正在创造更具吸引力的中长期配置条件，随着市场情绪逐步修复，估值与基本面重新匹配有望带来结构性机会。
