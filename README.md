        昨天还是医药风光无限，今天一开盘，半导体、存储芯片、GPU、HBM就集体冲了出来。创业板高开超过1%，科创板表现更强，科技股重新成为盘面最热的方向。表面看是市场人气恢复，实际上更像是资金又开始了一轮快速轮动。情绪真高昂，乌合之众的情绪是最容易被调动的，不过亢奋快，萎靡也快！
         问题恰恰就在这里。昨天炒医药，今天炒科技，前几天又是贵金属、油气、航运轮番表现，热点一天一个样，这种行情看起来热闹，实际上很容易重新走向“遍地开花”。我一直认为，市场真正需要的不是每天换一个板块上涨，而是资金能够集中到少数真正有业绩、有估值支撑的方向上，否则热点越多，资金反而越分散。
        今天科技股的强势也有外部因素。隔夜美股科技和半导体明显上涨，费城半导体指数大涨，英伟达产业链、英特尔、AMD等科技股表现强劲，对今天A股半导体、存储和AI硬件形成了直接刺激。 但我还是那个观点：涨得最凶的地方，不一定就是最值得追的地方。尤其是科技概念经过反复炒作以后，真正能够称得上低估值、又有业绩支撑的股票并不多。
          所以，我不会因为今天半导体涨得很猛，就轻易改变此前的判断。现在更应该看到的是，创业板上方压力依然很大，而真正需要完成的调整还没有完成。创业板377天线没有真正触及之前，我仍然不会认为这一轮调整已经结束，反而越是快速冲高，越要提防再次冲高回落。
           这几天市场其实已经反复证明一个问题：边跌边涨、热点轮番切换，看起来指数没有跌多少，但调整的压力始终没有释放干净。如果市场重新回到这种“今天医药、明天科技、后天再换一个板块”的模式，那么很可能只是重蹈覆辙。真正健康的行情，不应该是满市场到处找上涨理由，而应该是资金逐渐形成清晰而持续的主线。
          我的判断仍然很明确：创业板377天线不到，调整就不能算真正结束；反弹越热闹，越不能忘记上方的压力。 与其每天追着热点跑，我更愿意继续持有前面看好的低估值、真正有业绩支撑的股票，等待市场把调整压力释放出来。昨天医药，今天科技，明天又是谁？如果答案每天都在变化，那么市场真正的方向其实还没有出现。
