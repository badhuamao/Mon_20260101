         更值得注意的是，遍地开花最容易制造一种市场很强的错觉。 今天早盘虽然仍有粮食、油服工程等局部板块表现，但黄金、房地产、半导体等方向出现调整，市场超过3400只股票下跌。 当热点越来越多、持续时间越来越短，资金不断追逐新的题材，最终就会出现一个问题：谁都想上涨，却没有足够的资金让所有板块同时上涨。于是，一旦指数遇到压力，前期涨幅较大的品种就容易出现集中兑现。
        所以，我对目前市场的判断仍然没有改变：真正值得关注的不是今天哪一个板块涨停，而是资金有没有重新形成主线。 如果只是今天这个板块涨、明天那个板块涨，后天又换另外一个板块涨，那么这种行情很难形成持续性。相反，经过调整以后，如果资金重新集中到少数具有业绩、估值和实际产业逻辑支撑的方向，市场才更容易走出有质量的行情。
       今天的下跌并不是突然发生的，而是前期“遍地开花”之后的一次集中释放。 对后面的行情，我依然会重点观察市场能否从“遍地开花”重新回到“多点开花”，并观察指数重要支撑位置的确认情况。市场真正需要的不是更多热点，而是资金重新形成合力；在这个过程没有完成之前，越是到处热闹，反而越需要保持清醒。
