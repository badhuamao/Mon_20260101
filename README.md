摩根大通首席执行官杰米·戴蒙本周将前往印度。随着这家华尔街巨头加大对印度市场的拓展力度，该行预计当地交易活动将迎来进一步繁荣。戴蒙计划出席摩根大通在孟买举办的年度投资会议，并将在会上与印度大型企业集团的高管会面。近年来，戴蒙一直定期访问印度。摩根大通也在当地不断扩充投资银行、支付解决方案等业务领域的团队。去年，摩根大通在印度股票发行市场排名第一，在这个全球增长最快的经济体之一、也是最活跃的融资市场之一拔得头筹。摩根大通高管预计，这股热潮还将持续。“我们看到跨境并购、创新经济、制造业、医疗保健、消费、金融服务和科技等领域存在重大机遇，”摩根大通印度高级国家主管Rahul Badhwar在戴蒙访问前通过电子邮件表示。“随着印度企业继续向全球扩张，跨国公司进一步扩大在印度的业务，对战略咨询、融资和资本市场专业服务的需求只会不断增加。”
