【人气板块及个股点评】
今日短线情绪迎来修复回暖，市场赚钱效应显著抬升，全市场超3700只个股收涨，连板梯队晋级率突破五成。题材呈现出分化轮动态势，机器人板块领涨盘面，大业股份、京城股份走出3连板；物理AI分支弹性突出，凡拓数创拿下20CM2连板，奥比中光、索辰科技同步大涨超10%。低空经济、军工板块整体虽然分化整理，但前排标的继续接力走强，吉大正元斩获4连板，东安动力、海洋王、长春一东晋级3板。PCB概念股再度冲高回落，除了骏亚科技封板以外，则成电子、迅捷兴、金百泽、澳弘电子等均留下较长的上影线。与此同时，部分高位标的维持强势震荡，走出趋势连板行情，九阳股份再度封板，录得12天7板，百洋股份8天6板。

机构重申对Meta强力买入评级 看好公司基本面
雷蒙德·詹姆斯（Raymond James）重申对Meta强力买入评级，目标价维持860美元。该股当前报价705.44美元。 该行指出，Meta会早于其他大型云厂商披露财报。自8月底以来，该股累计涨幅超20%，而同期标普500仅上涨0.3%，市场对本次财报预期已经抬得较高。 雷蒙德·詹姆斯表示，广告渠道调研反馈向好，市场对其广告体系带来的投入回报认知仍不足；针对Meta全新重构的超级智能训练集群的AI训练相关调研结果同样乐观。该行认为，财报前整体预期偏中性，市场一致预期中远期费用与资本开支预估偏低。公司基本面依旧扎实，过去十二个月毛利率高达81.75%，营收增速27.65%。
