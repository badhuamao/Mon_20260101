         今天A股早盘没有出现明显的单边行情，三大指数小幅低开后继续震荡。盘面上半导体、PCB、小金属、风电设备相对活跃，而网络安全、传媒、汽车等方向偏弱。表面看热点不少，实际上资金依然是在存量市场里快速轮动。
         我还是那个观点：现在最重要的不是急着判断反弹来了没有，而是看创业板这一轮调整到底有没有走完。 昨天创业板已经跌到3247点附近，跌幅达到1.15%，而且市场成交进一步缩量，超过4300只个股下跌。这个调整显然还没有真正释放干净。
          所以，创业板的377天线我依然认为必须认真对待。没有真正打到这个位置，就很难说调整已经彻底结束。 我反而不怕它快一点跌，最怕的是每天磨一点、跌一点，看起来指数没什么问题，实际上风险一直没有释放。
          今天盘面比较有意思的是，PCB、半导体、小金属和风电又开始轮动。PCB概念继续活跃，澳弘电子出现4连板，风电板块也延续强势。 这说明资金并没有完全离场，只是在寻找新的突破口。
          但我要提醒一点：热点多，不等于行情已经重新转强。 如果什么板块都涨一点、资金到处开花，最后很容易重新回到“遍地开花”的老问题。现在真正需要的是有序轮动，而不是所有方向一起冲。
          股市真正的机会，往往不是在所有人都觉得安全的时候出现，而是在压力释放之后，资金重新找到方向的时候出现。现在这个阶段，耐心比追涨更重要。
