2026.9.18【收评：新的行情开始了吗？】
       昨天冲高回落，今天马上重新拉起来，而且比昨天更加热闹。创业板一度涨幅超过2%，科创50更是接近4%，半导体、存储芯片、光刻胶、算力硬件集体上涨，市场一度超过4500只股票上涨。看起来很强，实际上我看到的还是两个字：重蹈覆辙。
         我们前面已经说得很清楚，遍地开花必然带来调整。市场刚刚经历一次冲高回落，资金没有重新集中到真正安全的低估值方向，反而又开始到处寻找热点。今天半导体涨、消费涨、机器人涨、次新股也涨，资金再次撒胡椒面，这种行情短期可以很热闹，却很难真正走远。
          尤其是科技概念，我的观点没有改变。半导体今天确实强，部分个股甚至出现涨停潮，但问题还是那个问题：科技股里面真正让我们敢于长期持有的低估值股票并不多。如果资金继续靠概念、题材和高估值推动行情，那么涨得越疯狂，后面的压力反而越大。今天的上涨，并没有改变这个基本事实。
         创业板同样如此。今天涨得很猛，并不意味着上方压力消失了。恰恰相反，指数越往上走，前期套牢盘和短线获利盘越容易出来。创业板上方压力依然很大，377天线还没有真正到位，这一轮调整就不能轻易宣布结束。
         我并不反对反弹，但我反对这种没有经过充分调整、又重新“遍地开花”的反弹。真正健康的行情应该是资金越来越集中，估值越来越合理，最后形成一条能够持续的主线。现在恰恰相反，机构还是在老生常谈地炒作热门概念，哪里热就往哪里冲，至于估值是不是高、公司是不是值得长期持有，似乎已经被抛到脑后。
         我的判断依然简单：创业板377天线没有到，调整就没有真正结束；市场重新陷入遍地开花，反弹就很难持久。与其追逐今天突然冒出来的热点，不如继续守住前面已经看好的低估值股票，耐心等待市场重新寻找真正有价值的方向。
