2026.9.15【午评：无头苍蝇没戏】
        今天这个市场，我还是那个观点：别被表面的热闹骗了。现在最重要的事情，不是指数能不能马上涨回来，而是资金到底往哪里走。经过前几天的快速调整，市场已经开始出现新的分化，有些低位方向重新获得关注，而前期涨幅过大的科技股压力依然不小。
        真正健康的行情，本来就不可能所有股票一起涨。前面我一直说“多点开花可以，遍地开花不行”，原因就在这里。资金只有从一个方向撤出来，再去寻找另一个方向，市场才会有持续的机会。所以今天看到风电、电力、部分周期方向活跃，我反而觉得比什么题材全部上涨更有意义。
         9月11日快速下跌以后，9月14日创业板又跌了1.10%，收在3285.58点。 377天线这个位置，我依然不会改变判断。 没有真正靠近甚至触及之前，我不会轻易宣布创业板调整结束。短线当然可以反弹，但反弹和调整结束是两回事。
         我现在更愿意把注意力放在证券、电力、燃气、油气、有色、贵金属以及低位周期这些方向上。至于那些高位、纯概念、缺乏业绩支撑的科技炒作，我还是那句话——市场需要给它们降降温。接下来如果指数继续震荡，我反而不悲观。
         因为只有指数把压力释放出来，资金完成重新分配，下一轮真正的主线才有可能浮现。市场不怕跌，怕的是跌不透；行情也不怕分化，怕的是再次遍地开花。这才是我今天看盘以后最想说的一句话。无头苍蝇，没戏！
