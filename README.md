【Anthropic数学家声称攻克困扰数学界160余年的黎曼猜想】金十数据11月21日讯，周五，Anthropic数学家Levent Alpöge在个人网站发布了一份4页的说明文件，称自己通过与Anthropic的人工智能系统Claude合作，完成了黎曼猜想的证明。他没有附上传统形式的数学论文来阐述证明过程，而是提供了一段计算机代码的链接，并声称这段代码能够验证证明结果。其他研究人员表示，他们正在检查Alpöge的代码。该代码使用Lean语言编写，这是一种能够将数学命题转化为可验证形式的编程语言。如果Lean代码不存在错误，就意味着证明过程的逻辑是严密的。黎曼猜想认为，即使素数的出现看似毫无规律，其分布背后仍存在一定的数学规律。该猜想是数学界公认的七大难题之一。一旦其证明获得正式认可，将成为数学史上的重要事件。
