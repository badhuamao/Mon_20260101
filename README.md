摩根士丹利 称数据中心资产支持证券或需调整交易结构
摩根士丹利一份研报指出，投资者希望债券存续期内能够实现部分或全部去杠杆，数据中心资产支持证券（ABS）交易可能需要做出结构性调整。策略师 Carolyn Campbell、James Egan 以及 Vishwanath Tirupattur 在报告中写道，我们认为，投资者对 AI 整体叙事信心下滑，并不是数据中心 ABS 需求走弱的原因。在我们看来，数据中心证券化信贷市场显然正在趋于饱和，至少当前这类交易结构与资产特征已经到了这个阶段。短期来看，数据中心发行方大概率仍会在现有主信托框架内操作，推出贷款价值比更低、久期更短的交易，并以明显折价发行债券。利差可能继续走阔，但当前水平具备吸引力，短久期品种尤为突出。在固收市场各类标的里，数据中心 ABS 发行体量独立；即便相比其他 ABS 债券利差更高，也未必能自动吸引新增需求。对发行方而言，基准利率带来的压力或许更大。

花旗 ：美国小盘股做空仓位接近历史极值，警告空头回补可能引发股价大幅反弹
花旗10月27日指出，美国小盘股的做空仓位仍接近历史最高水平，一旦出现利好消息，可能引发大规模空头回补，推动股价快速反弹。该行表示，罗素2000指数的看空仓位已处于历史极端水平，且大量做空者目前仍有可观盈利，若市场情绪改善，这些投资者可能集中买回股票平仓，进一步放大上涨幅度。过去一周，全球投资者普遍削减股票仓位并增加做空押注，其中纳斯达克指数的看多仓位在过去两周明显下降，但整体仍保持净多头。欧洲市场此前的资金流入趋势逆转，英国富时100指数转为净空头，德国DAX及欧洲斯托克指数的做空仓位增加；亚洲市场看空情绪则更为突出，恒生指数和韩国KOSPI指数的做空仓位均接近历史极值。花旗认为，当前市场情绪仍偏悲观，但做空交易过于集中，也意味着一旦出现利好，股市可能迎来较大幅度的反弹。

摩根大通 增聘九人，强化小盘股投行业务布局
摩根大通组建了一支由 12 名投行人员构成的团队，其中包含九名新入职员工，专门服务小盘企业。这也是该行全球投行部门今年持续扩充团队的最新动作。一份内部备忘录显示，该团队服务标的企业估值区间为 1 亿至 5 亿美元。本次新加入人员之中包含四名董事总经理：驻休斯顿的 Gabe Gerenstein、驻纽约的 Mike Goettemoeller、驻迈阿密的 Roberto Hernandez 以及驻芝加哥的 Cameron Soelberg。Gori 在采访中表示：“我们希望在所有开展业务的产品、地区和国家做到第一。美国小盘股市场就是这一机遇的典型代表。这类企业想要加快扩张、把握战略机会、安排管理层接班，对投行专业建议的需求正在上升。”Gori 称，该业务重点覆盖医疗、科技、基建、私募股权出资方等赛道，同时布局日本、中东、非洲等地区。

机构：原有iPhone用户需求释放 Duo上市初期将供不应求
